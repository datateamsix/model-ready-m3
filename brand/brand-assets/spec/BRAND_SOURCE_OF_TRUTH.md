# Brand Source of Truth

## Approval hierarchy

1. `reference/prem3-approved-brand-board.png` — approved visual direction.
2. `reference/prem3-approved-primary-logo-reference.png` — canonical full-lockup visual reference.
3. Final approved Figma/vector master — once produced, this becomes the production geometry source of truth.
4. SVG/PNG exports generated from the approved vector master.
5. Frontend implementation.

If an implementation conflicts with a higher item in the hierarchy, the higher item wins.

## Non-authoritative details

Generated presentation-board artifacts can contain incidental labels, dates, microtype, or rendering artifacts. Do not copy those blindly. The canonical implementation values are the ones written in this package.
