# Small-Size Mark Specification

The full resolving-cube mark contains deliberate small fragments. Do **not** simply shrink the full mark to favicon size and assume it remains legible.

## Required small-size master

Create a separate `prem3-mark-small.svg` derived from the approved mark.

### Rules

- Preserve the same silhouette and left-to-right resolving idea.
- Remove only details that collapse optically at target size.
- Keep the resolved Cyan face unmistakable.
- Keep Deep Navy as the structural anchor.
- Preserve at least 1–2 unresolved gray cues where they remain legible.
- Do not invent new geometry or turn it into a generic cube.

## Deployment ladder

| Size | Asset | Tagline | Notes |
|---:|---|---|---|
| 16 px | small mark | no | maximum simplification; test on light/dark browser UI |
| 32 px | small mark | no | favicon baseline |
| 48–64 px | small/full mark based on visual test | no | nav/product chrome |
| 128+ px | full mark | optional | app/social/avatar contexts |
| 512+ px | full mark | optional | social, store, launch graphics |

## Acceptance test

At 16 and 32 px, the viewer should still read:
1. directional resolution from left to right;
2. a structured modular form;
3. Cyan resolved face;
4. no muddy cluster of indistinguishable tiles.
