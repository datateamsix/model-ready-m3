# Developer Handoff Checklist

- [ ] Read `README.md`.
- [ ] Confirm final vector masters have `APPROVED` status in the manifest.
- [ ] Use exported logo assets; do not recreate the artwork in CSS/JS.
- [ ] Import canonical tokens instead of hardcoding near-match colors.
- [ ] Use `prem3-mark-small.svg` for favicon / smallest product chrome.
- [ ] Use inverse assets on dark surfaces.
- [ ] Confirm no runtime font is required to render the official wordmark.
- [ ] Test logo rendering on 1× and 2× pixel density.
- [ ] Run side-by-side visual review before release.
