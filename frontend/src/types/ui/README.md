# Frontend-Only Presentation Types

Types that describe how the UI presents data, not backend contract shapes — plan-badge display
variants, project-allowance summaries, and similar view-model types built in Mission 2's
`M2-03` (commercial domain and navigation foundation) onward. Distinct from
`frontend/src/types/generated/` (backend contract types, once generated) and from Mission 1's
hand-mirrored contract types at the top of `frontend/src/types/` — those represent backend
truth; this directory never does.
